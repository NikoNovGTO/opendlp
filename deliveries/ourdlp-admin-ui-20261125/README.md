# OurDLP 0.8.1 — русскоязычная консоль, 25.11.2026

- **OurDLP-admin-ui-source.zip** — полные исходники, семь проектов, Visual Studio 2026 18.x / .NET 10.
- **OurDLP-admin-ui-server-desktop-win-x64.zip** — готовые сервер/консоль Windows x64; нужны Desktop/ASP.NET Core Runtime .NET 10.
- **OurDLP-admin-ui-agent-win-x64.zip** — агент и пользовательский компонент Windows x64 с включённым .NET runtime.

В консоли добавлены обзор с быстрыми переходами, боковое меню и три шага настройки буфера: политика, компьютеры, журнал. Состояния показывают включение/выключение наблюдения, ожидание получения, частичное применение, отсутствие подтверждения пользователя и потерю связи. Для выбранного компьютера есть пояснение и следующее действие. Поиск и фильтр применяются к загруженным данным, а ошибка обновления явно помечает последние сведения как устаревшие. Несохранённый черновик и фильтры сохраняются при обновлении. Скрытый фильтром компьютер нельзя случайно использовать для назначения.

Наши PowerShell-сообщения переведены на русский. Ярлык — **«OurDLP — Контроль буфера обмена»**; прежний английский ярлык удаляется только при совпадении с установленным путём OurDLP.Session.exe. Служба отображается как «OurDLP — Агент компьютера», технический идентификатор OurDLP.Agent сохранён.

**Обновление с 0.8:** распакуйте исходники в новую папку и запустите Server + Desktop. Новых миграций нет; база, администратор и формат очередей сохраняются. Агент обновите через Update-Agent.ps1 от администратора, затем запустите русский ярлык обычным пользователем. С 0.7 сначала Apply-DatabaseMigrations.ps1. Полные инструкции — ADMIN-INTERFACE.md и CLIPBOARD.md внутри архивов. Графический установщик пока не реализован.

Release без ошибок/предупреждений. **185 проверок логики/файлов/PostgreSQL + 24 live-HTTPS = 209** без пропусков. Синтаксис 11 скриптов PowerShell и состав Windows x64/ZIP/runtime проверены. SHA256 рядом. Содержимое буфера не передаётся, копирование и вставка не блокируются.

**Внешний вид WPF/DPI, Win32-захват, трей, Windows autorun/ярлыки, pipe/impersonation, SCM, DPAPI и ACL здесь не запускались и требуют проверки на Windows.** Общая логика проверена в облачной Linux-среде; целевая платформа — Windows. master и прежний OpenDLP не изменены. Частные ключи, User Secrets, реальные тестовые пароли и очереди не поставляются.
