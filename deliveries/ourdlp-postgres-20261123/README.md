# OurDLP 0.2 — PostgreSQL, 23.11.2026

Новая версия самостоятельного OurDLP. Исходники legacy OpenDLP в master не изменялись.

- **OurDLP-postgres-source.zip** — решение Visual Studio, EF Core/Npgsql, первая миграция, клиент и тесты.
- **OurDLP-postgres-win-x64.zip** — Windows x64 EXE с зависимостями EF/Npgsql и локальными скриптами настройки; требуются установленные .NET 10 runtimes и PostgreSQL.

Распакуйте исходники в новую папку, откройте OurDLP.slnx. Из терминала PowerShell в папке решения выполните `./tools/Initialize-LocalDatabase.ps1`. Пароль PostgreSQL вводится только на вашем компьютере. Затем запустите Server + Desktop и нажмите «Проверить соединение». Должны отображаться «API доступен» и «База готова».

Мастер не устанавливает PostgreSQL и не перезаписывает существующие базы/пароли. Для существующей базы предусмотрен Configure-ExistingDatabase.ps1. Подробные инструкции в README.md и DATABASE-SETUP.md внутри ZIP.

Готово: подключение PostgreSQL, миграция таблицы devices, явное применение миграций, отдельная готовность API/БД. Агент, авторизация и сканирование в этот этап не входят.

Проверки: 44 случая с реальной PostgreSQL 17 и 8 через реальный HTTPS прошли. Мастер выполнен с чистой тестовой базой, повторно и в режиме существующей базы. Сборки опубликованы для Windows x64; WPF-интерфейс на Windows и обнаружение Windows-установки PostgreSQL здесь не запускались. Сертификаты и пароли в архивы не включены.
