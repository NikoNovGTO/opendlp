# OurDLP 0.6 — задания агента и серверные отчёты, 24.11.2026

- **OurDLP-remote-source.zip** — исходники Visual Studio 2026 / .NET 10, шесть проектов.
- **OurDLP-remote-server-desktop-win-x64.zip** — готовые сервер и консоль x64; .NET 10 Desktop/ASP.NET Core Runtime, SDK для мастеров настройки.
- **OurDLP-remote-agent-win-x64.zip** — новый агент 0.6 x64, .NET включён, установка/обновление/демокаталог.

Обновление: остановить старые приложения, распаковать в новую папку, выполнить ./tools/Apply-DatabaseMigrations.ps1. Администратор, пароль и данные сохраняются. Запускать только Server + Desktop, войти прежними данными. Для заданий требуется обновить агент до 0.6; старый 0.4 продолжит heartbeat, но задания не получает.

Вкладка «Задания агента»: выбрать устройство и путь в объявленной области, правило, исключения и размер; создать задание, дождаться выполнения, открыть отчёт и экспортировать CSV. Параметры фиксируются на сервере, общий Core выполняется на агенте. Область пока ограничена ProgramData/OurDLP/ScanTargets; установщик готовит Demo с тремя совпадениями в двух файлах.

Второй ПК не обязателен для первого испытания: **SINGLE-PC-DEMO.md** внутри всех архивов описывает сервер/консоль/службу на одной машине через localhost HTTPS. LocalDemo не открывает Firewall. Для двух ПК — AGENT-SETUP.md и REMOTE-SCANNING.md.

Задание сохраняется до чтения, отчёт — до подтверждения сервера. При обрыве связи сохраняется очередь, повтор не дублирует результат. Есть отмена в процессе работы, отмена заданий при отзыве устройства, проверка владельца/области/неизменности результата. На сервере метаданные JSONB, на агенте DPAPI/ACL. Найденные строки отдельно не отправляются. Каталог политик/расписание и DLP-блокировка остаются следующим этапом.

Проверено: Release без ошибок/предупреждений; 127 случаев логики/файлов/PostgreSQL и 20 live-HTTPS, всего 147 — прошли без пропусков. HTTPS-проверка включает реальный агентский клиент и отчёт с 92 обнаружениями. Синтаксис 10 PowerShell-скриптов, PE/runtimeconfig, Core в публикации, ZIP и отсутствие тестовых секретов проверены.

Windows SCM/DPAPI/ACL/NTFS, выпуск сертификата Windows, фактическое обновление/rollback службы и WPF здесь не запускались: облачная среда Linux. Порядок одного ПК требует первого реального Windows-испытания. Подробности — VALIDATION.md.

Изменения только в новом каталоге ветки доставки. master и старый OpenDLP не изменены. Пароли, локальные сертификаты/закрытые ключи, User Secrets и очереди в архивы не входят.
