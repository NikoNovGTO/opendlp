# OurDLP 0.4 — устройства и агент, 24.11.2026

- **OurDLP-agent-source.zip** — решение Visual Studio 2026 / .NET 10, пять проектов. Для продолжения разработки скачайте этот архив.
- **OurDLP-server-desktop-win-x64.zip** — сервер и консоль Windows x64; нужны .NET 10 Desktop/ASP.NET Core Runtime, SDK для мастеров настройки.
- **OurDLP-agent-win-x64.zip** — отдельный агент второго ПК; self-contained, .NET включён.

## Обновление с работающей 0.3

Остановите сервер и консоль, распакуйте в новую папку. Из папки решения выполните `./tools/Apply-DatabaseMigrations.ps1`. Прежние данные и администратор сохраняются. Запускайте только Server + Desktop, вход прежним паролем. Появилась вкладка «Устройства».

Для второго ПК следуйте AGENT-SETUP.md внутри ZIP: настройте LAN HTTPS на первом ПК, выдайте код в консоли, скопируйте публичный сертификат и сверьте SHA256, локально установите агент с правами администратора. Пароль администратора и закрытый ключ не передаются. Код действует 15 минут. Удалённая установка из консоли пока не реализована.

Служба OurDLP.Agent сообщает состояние каждые 30 секунд. Консоль показывает имя/ОС/версию/IP/время, обновляется раз в 15 секунд, «Нет связи» — после 90 секунд. Есть перевыпуск кода и отзыв доступа. Хеши токенов на сервере, DPAPI и ACL на агенте. Сканирование и политики DLP — следующие этапы.

Проверено: Release без ошибок/предупреждений; 74 проверки логики/PostgreSQL и 16 live-HTTPS случаев, все прошли. PowerShell: синтаксис. PE/runtimeconfig и целостность ZIP проверены. WPF, SCM, DPAPI, ACL/Firewall/сертификаты Windows и два Windows-ПК в Linux-среде не запускались: требуется первое испытание на тестовых Windows-ПК. Протокол — VALIDATION.md.

Приватные ключи, пароли, User Secrets и состояние агентов в архивы не входят. Изменения только в этом новом каталоге ветки доставки; master и старый OpenDLP не изменены.
