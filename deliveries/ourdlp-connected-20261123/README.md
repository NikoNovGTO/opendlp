# OurDLP: проверка подключения — 23 ноября 2026

Архивы самостоятельного проекта OurDLP, размещённые для передачи владельцу репозитория. Это не сборка legacy OpenDLP из корня репозитория.

- `OurDLP-connected-source.zip` — исходники решения Visual Studio (.NET 10, WPF, ASP.NET Core), общий контракт и тесты.
- `OurDLP-connected-win-x64.zip` — framework-dependent сборка Windows x64. Нужны .NET Desktop Runtime 10 x64 и ASP.NET Core Runtime 10 x64; инструкция и Start-OurDLP.cmd находятся внутри.
- `SHA256SUMS.txt` — контрольные суммы архивов.

Реализована ручная проверка HTTPS-соединения и единое состояние на главной и в настройках. Авторизация, PostgreSQL и агент в этот этап не входят.

Проверено: Release-сборка без предупреждений/ошибок; 30 тестов логики; 3 сценария реального HTTPS с сохранённой проверкой сертификата. Windows EXE собраны, но WPF-интерфейс в облачной Linux-среде не запускался.

Распакуйте исходники в новую папку, откройте OurDLP.slnx и настройте одновременный запуск Server и Desktop. На вашем компьютере с SDK для локального HTTPS используется собственный сертификат разработки (`dotnet dev-certs https --trust`). Чужие сертификаты и приватные ключи в архивы не включены.
