# OurDLP 0.3 — вход администратора, 24.11.2026

Новый этап самостоятельного OurDLP. Старые исходники OpenDLP и master не менялись.

- **OurDLP-auth-source.zip** — исходники решения Visual Studio 2026 / .NET 10.
- **OurDLP-auth-win-x64.zip** — framework-dependent Windows x64 сборка и мастера настройки.

## Обновление с 0.2

Остановите старые сервер и консоль, распакуйте в новую папку. Из PowerShell в папке решения/сборки выполните `./tools/Create-Administrator.ps1`. Мастер применит миграцию к существующей PostgreSQL и попросит создать новый пароль OurDLP. Логин по умолчанию admin. Пароль 12–128 символов, с заглавной/строчной латинскими буквами и цифрой. Это отдельный пароль от PostgreSQL/Windows.

Затем запустите Server + Desktop (F5 из исходников или Start-OurDLP.cmd из готовой сборки) и войдите на https://localhost:7443. После входа откроется главная; имя и «Выйти» в верхней панели.

Существующая конфигурация базы и устройства сохраняются. Повторный мастер не сбрасывает прежний пароль администратора. Для новой базы сначала Initialize-LocalDatabase.ps1.

Готово: ASP.NET Core Identity, хеши паролей, административная политика API, окно входа, память cookie, logout с отзывом других/скопированных сеансов, блокировка после ошибок, ограничение попыток, аудит. Без сетевой регистрации пользователей.

Проверено: Release без ошибок/предупреждений, 62 теста логики/PostgreSQL и 12 live-HTTPS случаев. Вход, защищённый запрос и выход выполнены настоящим AuthenticationClient. Мастер и повторное создание проверены на локальной тестовой PostgreSQL. Windows EXE собраны, но WPF-окно, Windows DPAPI и политики PowerShell в Linux-среде не запускались. Подробности в AUTHENTICATION.md и VALIDATION.md внутри ZIP.

Приватные ключи, сертификаты и пароли в архивы не включены. Авторизация — этот этап; агент и сканирование ещё впереди.
