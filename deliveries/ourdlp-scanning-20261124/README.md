# OurDLP 0.5 — проверка файлов на одном ПК, 24.11.2026

- **OurDLP-scanning-source.zip** — исходники Visual Studio 2026 / .NET 10, шесть проектов, включая новый OurDLP.Core.
- **OurDLP-scanning-win-x64.zip** — Server/Desktop x64; нужны .NET 10 Desktop Runtime и ASP.NET Core Runtime, для мастеров — SDK .NET 10.

Остановите старые приложения, распакуйте в новую папку, выполните `./tools/Apply-DatabaseMigrations.ps1`. Учётная запись и база сохраняются. Откройте OurDLP.slnx, запускайте только Server + Desktop, вход прежним паролем.

На вкладке **«Проверка файлов» → «Создать тестовый каталог» → «Начать проверку»** ожидаются три совпадения в двух файлах. Второй компьютер не нужен. Доступны выбор папки/регулярного выражения/исключений/размера файла, прогресс, отмена с частичным результатом, замечания, последние 20 проверок и CSV. Анализируются TXT/CSV/LOG, UTF-8 и UTF-16 с BOM. Исходные файлы не изменяются, тексты совпадений отдельно не сохраняются. Инструкция — LOCAL-SCANNING.md.

Это локальная проверка на ПК с консолью. Агент 0.4 сохраняет регистрацию и heartbeat; обновлять его для этой функции не нужно. Политики, проверка на агенте и передача обнаружений в PostgreSQL — следующий этап. Инструкция прежнего агента сохранена в AGENT-SETUP.md.

Проверено: Release шести проектов без ошибок/предупреждений, 102 проверки логики/файлов/PostgreSQL и 16 live-HTTPS случаев — все прошли. Новый код разделён на небольшие классы; самый большой новый производственный класс — 114 строк. PE/runtimeconfig, наличие Core в публикации, целостность ZIP и отсутствие тестовых секретов проверены.

WPF, диалоги Windows, NTFS/junction/ACL, SCM, DPAPI и два Windows-ПК в Linux-среде не запускались. Новую вкладку нужно визуально проверить в Windows; общая логика, чтение файлов, история, CSV, сервер и протоколы проверены здесь. Подробнее — VALIDATION.md и ARCHITECTURE.md внутри ZIP.

master и старый OpenDLP не изменены. В этой поставке нет приватных ключей, паролей, локальных User Secrets, истории и состояния агентов.
