# OurDLP 0.7 — текст DOCX/XLSX, 24.11.2026

- **OurDLP-office-source.zip** — исходники Visual Studio 2026 / .NET 10, шесть проектов.
- **OurDLP-office-server-desktop-win-x64.zip** — сервер и консоль x64; нужны .NET 10 Desktop/ASP.NET Core Runtime, SDK для мастеров.
- **OurDLP-office-agent-win-x64.zip** — агент 0.7 self-contained с .NET, установка и обновление.

В общий Core добавлены DOCX/XLSX: Word-текст/таблицы/колонтитулы/сноски/комментарии и Excel-ячейки/скрытые листы/shared/inline/rich strings/сохранённые значения формул. Microsoft Office и Интернет для извлечения текста не нужны. Формулы и макросы не исполняются. PDF/старые DOC/XLS/вложения/OCR остаются вне этого этапа.

На одном ПК: распаковать исходники отдельно, запустить Server + Desktop, войти прежними данными. «Проверка файлов» → «Создать тестовый каталог» → «Начать проверку»: свежий Demo даёт **5 проверенных файлов, 4 строки обнаружений, 7 совпадений**. Новых миграций после 0.6 нет; для старой базы Apply-DatabaseMigrations.ps1, без повторного создания администратора.

Для Office через службу нужен новый агент 0.7: Update-Agent.ps1 сохраняет регистрацию/очередь и добавляет недостающие демонстрационные документы без замены существующих. При прежнем сервере сертификат и код менять не нужно. Готовые старые отчёты досылаются без пересканирования; после обновления создайте новое задание. Новая установка и сценарий службы на одном ПК — SINGLE-PC-DEMO.md. Охват и ограничения — OFFICE-SCANNING.md.

Добавлены ограничения распаковки, сжатия, XML, текста, времени и предварительная проверка каталога ZIP, в том числе реального числа записей. DTD и внешние загрузки отключены, повреждённые/защищённые/неподдерживаемые пакеты отмечаются в отчёте. Найденные строки отдельно не сохраняются. Классы разделены; самый большой новый файл чтения форматов — 78 строк.

Проверено: Release без ошибок/предупреждений; 149 проверок логики/файлов/PostgreSQL + 20 live-HTTPS, всего 169, без пропусков. 22 новых Office-случая; независимые python-docx/openpyxl-файлы и чтение сгенерированных Demo. Реальная HTTPS-цепочка включает Office и отчёт с 94 обнаружениями/97 совпадениями. PowerShell: синтаксис 10 скриптов. PE/runtimeconfig, Core, ZIP и отсутствие тестовых секретов проверены.

Microsoft Word/Excel GUI, WPF, Windows SCM/DPAPI/ACL и фактическое обновление службы в Linux не запускались. Эти шаги требуют Windows-теста. Протокол — VALIDATION.md. master и старый OpenDLP не изменены. Пароли, закрытые ключи, локальные сертификаты, User Secrets и очереди в архивы не входят.
