# OurDLP 0.8.2 — один архив для демонстрации, 25.11.2026

- **OurDLP-demo-win-x64.zip** — готовый комплект Windows x64: сервер, консоль, агент, пользовательский компонент, .NET runtime, окно запуска и сценарий показа. Visual Studio/SDK не нужны.
- **OurDLP-demo-source.zip** — полные исходники Visual Studio 2026 / .NET 10, семь проектов и скрипты сборки комплекта.

**Первый запуск:** распакуйте полностью, закройте прежний сервер/консоль из Visual Studio, откройте **ЗАПУСТИТЬ.cmd обычным пользователем Windows**. Нажмите проверку готовности; при необходимости выполните первичную подготовку, затем запустите сервер и консоль. Установка/обновление агента и тестовый текст доступны отдельными кнопками. Инструкции ЧИТАТЬ.txt и ПОКАЗ.txt находятся рядом.

Требуется установленный и запущенный PostgreSQL 17. Для первого подключения к нему нужен пароль postgres; если администратор OurDLP уже существует, его пароль сохраняется. Подготовка/установка службы повышают права под тем же пользователем Windows. Комплект использует существующую локальную конфигурацию и базу OurDLP, а не изолированную копию; смены регистрации агента на другой сервер автоматически нет. С 0.8 новых миграций нет. Первичную подготовку выполните до публичного показа.

Сценарий: политика → подтверждение наблюдения → копирование тестового маркера → событие в журнале → временная остановка своего сервера → доставка после восстановления. Файловый Demo: TXT/CSV/LOG/DOCX/XLSX, 5 файлов / 4 строки / 7 совпадений. Это наблюдение без блокировки, тексты буфера не сохраняются и не отправляются. Подставные обнаружения не добавляются.

Программы сохраняют свои версии DLL; одинаковые байты хранятся один раз. При запуске приложения восстанавливаются по SHA256 в отдельные каталоги LocalAppData. Кнопка остановки проверяет путь и время создания процесса; чужой сервер не останавливается. Закрытие окна запуска оставляет сервер и службу работать.

Release без ошибок/предупреждений. **190 проверок логики/файлов/PostgreSQL + 24 live-HTTPS = 214** без пропусков. Дополнительно 14 переносимых PowerShell-проверок, три случая настоящего локального CLI, синтаксис 20 PowerShell-файлов. Состав, self-contained runtimeconfig, PE Windows x64, хеши и ZIP проверены; реальные тестовые секреты исключены.

**Нативные WinForms/WPF, UAC, Windows PowerShell 5.1, SCM, DPAPI, ACL/сертификаты/ярлыки Windows, настоящий захват буфера и запуск опубликованных Windows-программ здесь не выполнялись.** Перед публичным показом требуется репетиция на Windows по ПОКАЗ.txt. Целевая платформа — Windows; облачная среда использовалась для сборки и переносимых проверок. master и прежний OpenDLP не изменены.
