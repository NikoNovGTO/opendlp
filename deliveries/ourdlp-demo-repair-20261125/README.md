# OurDLP 0.8.2 — исправление восстановления агента, 25.11.2026

- **OurDLP-demo-repair-update.zip** — маленькая поправка для уже распакованного демонстрационного комплекта. Распаковать прямо в папку с ЗАПУСТИТЬ.cmd с заменой файлов; внешней папки в ZIP нет.
- **OurDLP-demo-repaired-win-x64.zip** — полный комплект с поправкой; можно распаковать в новую папку.
- **OurDLP-demo-repaired-source.zip** — обновлённые исходники Visual Studio.

Исправлена ошибка «Папка агента уже существует, но служба отсутствует». Прежняя папка программы сохраняется рядом как Agent-before-repair-<GUID>; затем устанавливаются проверенные файлы и создаётся служба. При ошибке до/после создания службы предусмотрен возврат прежней папки. Защищённая регистрация и очереди в ProgramData не удаляются. Если Windows не позволяет убрать незавершённую службу, файлы сохраняются для проверки.

При наличии сохранённой регистрации агент проверяет её через настоящий HTTPS heartbeat без нового кода и смены токена. Другой сервер и отозванная регистрация автоматически не заменяются: для этого нужна явная перерегистрация. Для нового агента код запрашивается как прежде. Исполняемые файлы и manifest payload/apps.json 0.8.2 побайтно прежние.

**Для текущей ошибки:** нажмите Enter в окне ошибки, распакуйте маленькую поправку в существующую папку с ЗАПУСТИТЬ.cmd, подтвердите замену и повторно нажмите «Агент на этом ПК». Сервер можно оставить работающим. Подробности — ВОССТАНОВЛЕНИЕ.txt в поправке.

Release без ошибок/предупреждений. 193 проверки логики/файлов/PostgreSQL и 24 live-HTTPS — 217 без пропусков. Дополнительно 12 новых переносимых проверок резервирования/отката/режима регистрации; синтаксис 22 PowerShell-файлов. Проверены ZIP, SHA256, отсутствие реальных тестовых секретов и побайтная неизменность исполняемых файлов.
