## Что изменилось

В консоли появился раздел **Помощь** с поиском по семи темам. **F1** и кнопка верхней панели открывают инструкцию по текущему разделу. На рабочих экранах есть ссылки к нужной теме. Каждый шаг объясняет действие и ожидаемый результат; кнопки открывают точные вкладки, сохраняя черновик политики и не выполняя настройки автоматически.

В журнале и справке есть общий тестовый маркер и кнопка смены примера. Он служит для настоящего испытания агента, а не создаёт подставные события. Для состояний устройств добавлены пояснения и следующий шаг. Пустой список и отсутствие результатов поиска теперь объясняются отдельно.

Окно запуска открывает инструкцию внутри программы с тремя вкладками — первый запуск, показ буфера, устранение проблем. F1 работает и в нём. Помощь доступна также до входа в консоль. Интернет и внешний текстовый редактор для чтения справки не нужны.

## Как обновить

1. В **прежнем** окне запуска остановите свой сервер специальной кнопкой, затем закройте консоль и окно запуска. Службу агента для обновления справки останавливать не требуется.
2. Распакуйте полный комплект в новую папку либо маленькое обновление прямо в существующую папку с ЗАПУСТИТЬ.cmd, подтвердив замену файлов.
3. Откройте ЗАПУСТИТЬ.cmd обычным пользователем, запустите сервер и консоль. В консоли откройте «Помощь» → «Первый запуск».

База, настройки и регистрация используются прежние. Новые миграции не нужны. Исправление восстановления установки после ошибки «папка есть, службы нет» сохранено; оно не объявляется подтверждённым на ПК пользователя. Agent, Session и Server в готовом комплекте побайтно прежние из исправленного 0.8.2, новая версия консоли/комплекта — 0.8.3.

## Проверка и ограничения

Release и публикация win-x64 без ошибок/предупреждений. **202 теста** логики/файлов/настоящего PostgreSQL, включая 9 новых выполнений проверок помощи; без ошибок и пропусков. Отдельный целевой прогон 25 входит в эти 202. Дополнительно 14 переносимых проверок запуска, 12 проверок восстановления установки, синтаксис 23 PowerShell-файлов и загрузка трёх тем помощи. Проверены состав, хеши, self-contained PE Windows x64, целостность ZIP и отсутствие реальных тестовых секретов. Изменения доступны в `changes.diff`, контрольные суммы — `SHA256SUMS.txt`.

**Нативные окна WPF/WinForms, F1/масштабирование, Windows PowerShell 5.1, UAC/SCM/DPAPI/ACL и настоящий захват буфера здесь не запускались.** Приёмка на Windows описана в GUIDE.md внутри комплектов. Режим остаётся наблюдением: копирование/вставка разрешены, блокировка USB/печати/сетевых передач пока не реализована. master и прежний OpenDLP сохранены.
