# OurDLP 0.8 — буфер обмена, 25.11.2026

- **OurDLP-clipboard-source.zip** — исходники, семь проектов, Visual Studio 2026 18.x / .NET 10.
- **OurDLP-clipboard-server-desktop-win-x64.zip** — Server/Desktop x64, framework-dependent.
- **OurDLP-clipboard-agent-win-x64.zip** — Agent + Session x64 с включённым общим .NET runtime.

Добавлены версии политик, назначение компьютеру, фоновый анализ CF_UNICODETEXT в сеансе пользователя и журнал метаданных. Режим — наблюдение без блокировки; содержимое/фрагменты/хеш текста буфера не передаются и не сохраняются приложением. Кэш и очереди сохраняются с Windows DPAPI; повторная доставка идемпотентна. Это этап endpoint DLP, USB/печать/адресат вставки ещё не реализованы.

**Обновление:** новая папка исходников → tools/Apply-DatabaseMigrations.ps1 для существующей базы → Server + Desktop → Update-Agent.ps1 из нового агентского архива от администратора → OurDLP - Clipboard Monitor из Пуска обычным пользователем (или повторный вход в Windows) → сохранить включённую политику → назначить → дождаться подтверждения сеанса → скопировать новый тестовый маркер. Подробно: CLIPBOARD.md внутри архивов. Администратора/устройство заново создавать не нужно при прежнем адресе/регистрации.

В консоли показаны назначенная версия, кэш службы и фактическое подтверждение компонента. Интернет для анализа не нужен. Выход из компонента останавливает наблюдение; защиты от остановки пока нет. Отключение политики действует после доставки. Отзыв регистрации блокирует серверный доступ, но не отменяет офлайн-кэш мгновенно.

Release без ошибок/предупреждений. 172 проверки логики/файлов/PostgreSQL + 24 live-HTTPS = **196**, без пропусков. Проверены прежние Office-сценарии, новые версии/права/очереди/повторы, отсутствие текста в метаданных, предел HTTPS-пакета и синтаксис 11 PowerShell-скриптов. Миграция применена поверх тестовой базы 0.7. ZIP/PE/runtimeconfig/секреты проверены, SHA256 рядом.

**В Linux не запускались настоящий Win32-захват, трей, autorun, Windows pipe/impersonation, SCM, DPAPI, ACL, WPF и два Windows-ПК.** Проверка синтетического ввода через реальные Core/API/PostgreSQL/TLS не заменяет этот нативный тест. Первый тест на одном ПК описан в CLIPBOARD.md. Прежний OpenDLP и master не изменены; частные ключи, User Secrets и очереди в архивы не включены.
